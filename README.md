## 🚀 Featured Projects

### 🎧 Grain to Glory
An audio restoration workspace designed to reduce noise and crackle in historical recordings and compare original and restored audio.

- Next.js frontend and Python backend.
- Audio processing and before-and-after comparison.
- Exploring open-source audio restoration and speech-enhancement models.

**Live Demo:** [Grain to Glory](https://grain-sandy-eta.vercel.app)

### 🎓 CodeZone Certificate Generator
A certificate-generation application designed to simplify creating digital certificates for community events.

- PNG and PDF certificate generation.
- Node.js backend and canvas-based rendering.
- Reusable certificate-generation workflow.

### 📝 CodeZone Quiz Platform
A web application for organizing technical quizzes and managing participants and results.

- React and Vite frontend.
- Express.js backend.
- Database integration and quiz-management features.

### 🏛️ NITI-VRIDDHI
An AI-driven policy research and decision-support project exploring policy scenarios and their potential impacts.

- Interactive web interface.
- Data-driven analysis and AI-assisted decision support.
- Designed for policy exploration and impact assessment.
